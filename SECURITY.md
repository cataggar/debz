# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue containing exploit details, credentials, private keys,
or malicious corpus files. Include the affected revision, impact, minimal
reproduction, and whether the report involves an untrusted repository,
package, local state file, or transaction boundary.

If private reporting is unavailable, contact the repository owner privately
through the contact method on their GitHub profile and request a secure
channel. Maintainers will acknowledge a complete report, coordinate fixes and
disclosure, and credit reporters who wish to be named.

Only the latest `main` revision is currently supported. Never include real
secrets or production package-manager state in reports; use recognizable
canaries and synthetic roots.
